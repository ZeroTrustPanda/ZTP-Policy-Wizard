# ZTP Policy Wizard v2.3.0

POV Start is now a guided flow with one step on screen at a time.

## Guided POV
1. **Tenant readiness.** Read-only checks across ZIA, ZPA, Client Connector and ZDX. Licensing is now checked across the whole tenant.
2. **Build the POV.** Choose what is in scope: Zscaler Internet Access, Zscaler Private Access and Zscaler Digital Experience.
3. **Customer intake.** Enter the customer name, the prefix (generated from the name, editable), the internal domain (saved for Private Access), a preset and the baseline policies.
4. **Client Connector.** The forwarding and app profile wizard, guided. It runs whenever Internet Access or Private Access is in scope. Set up Windows, macOS or both, or skip it.
5. **Internet Access.** Scope, baseline (preselected from the intake) and rules, with every toggle.
6. **Private Access.** The ZPA wizard, pre-filled with a `*.<domain>` wildcard, common apps (Active Directory, file shares, intranet, RDP jump host) and the vertical's apps.
7. **Digital Experience.** The ZDX wizard, pre-filled with apps for the market segment.
8. **Dry run & apply.** One dry run covers everything. One apply follows, with live progress, and each product has an *Edit* button that goes back to its step.

## Licensing cautions
| Tier | Capabilities | Shown as |
|---|---|---|
| Core | URL Filtering, Cloud App Control, SSL Inspection, Advanced Threat Protection, Antivirus, Cloud Sandbox, web DLP, Cloud Firewall, DNS Security, Client Connector, Cloud Browser Isolation | ⚠️ caution when missing |
| Optional | Advanced Cloud Firewall, IPS, CASB, Gen AI security, EDM / IDM, Bandwidth Control, Deception, log streaming, Z-API | ℹ️ info |

The readiness check also flags subscriptions that end within 21 days, and ZPA tenants without AppProtection or Privileged Remote Access.

## Presets
| Preset | Baseline | ZPA (on top of the wildcard + common apps) | ZDX |
|---|---|---|---|
| Healthcare | HIPAA | Epic Hyperspace / Interconnect, Imprivata, PACS, Cerner | UpToDate, Epic UserWeb, Doximity, EHR web |
| Financial services | PCI DSS | Core banking, trading platform | Bloomberg, Workday, DocuSign |
| General enterprise | Balanced | — | Salesforce, Workday, DocuSign |
| Education (new) | Balanced | Student information system | Canvas, Google Classroom, PowerSchool |

Outlook Online is added to every preset, on top of the template's Microsoft Login, Teams, Zoom and Webex probes. The intranet is monitored too.

## Navigation
- The global prefix bar has been removed. The prefix comes from the customer intake.
- **Bulk Rule Manager** is one sidebar item, above Policy Catalog, with tabs for ZIA, ZPA and ZDX.
