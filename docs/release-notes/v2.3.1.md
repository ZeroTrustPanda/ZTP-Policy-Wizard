# ZTP Policy Wizard v2.3.1

## Private Access: editable application table
- Each application's name, destinations (FQDN, `*.domain`, IP or CIDR), TCP ports and UDP ports can now be edited in the table. This works for preset apps on the guided POV and for CSV uploads.
- The segment name (`<prefix>-<name>`) updates as you type. Invalid entries are flagged immediately and block *Next* until they are fixed.
- **+ Add application** adds a row by hand.

Everything else is as in [v2.3.0](v2.3.0.md).
